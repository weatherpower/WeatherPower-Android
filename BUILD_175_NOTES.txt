WeatherPower 1.8.0 — Build 175

Version name: 1.8.0
Version code: 175

Radar 3.1 (phone) — tap the "3.1" button on the Radar tab, or More > Radar 3.1 & Tropics
- Radar products (WeatherPower render service /api/radar): high-res reflectivity, velocity, storm-relative
  velocity, CC, ZDR, KDP, hydrometeor classification (tilts 1–4), echo tops, VIL; site = nearest to map center
  or any NEXRAD site; status shows scan time/age and flags a radar that may be down
- Color tables: GR2Analyst / GRLevel3 / WxTools / RadarScope / JSON palettes from a file or a Drive, Dropbox or
  GitHub link (via /api/palette-fetch), per product, with unit conversion (mph/m·s⁻¹ → kt, % → CC, km → kft)
- MRMS storm damage layers: hail swath, low/mid-level rotation tracks, rainfall totals with the server's time
  windows; tap the map for the NOAA MRMS value
- Model Studio: HRRR / NAM / GFS / ECMWF from /api/models (catalog, runs, on-demand hours), playback,
  MSLP / 500 mb contours, tap for values
- Point soundings: Skew-T + hodograph from the HRRR profile or the nearest NWS balloon, or the SounderPy image
- Gas stations (every U.S. station, EIA weekly area prices) and public tornado shelters (capacity classes)
- Route weather: Mapbox driving route, NWS forecast at your arrival time and alerts along the way, gas and
  shelters near the route

Tropical Storm Center (More > Tropical Storm Center)
- Active storms from the NHC GIS forecast points (intensity, category, gusts, pressure, motion, position,
  advisory number/time) with public advisory and discussion links from NHC CurrentStorms.json
- Cones, forecast tracks/points, past tracks, coastal watches/warnings and the 7-day outlook (NHC MapServer,
  same layers as the Radar 3.1 website)
- GOES-19/GOES-18 sector imagery and storm floaters (NOAA/NESDIS STAR)

Android TV
- Leanback launcher entry + 320x180 banner; touchscreen/camera/location not required
- 10-foot UI with D-pad focus: Live Radar, Tropical, Alerts, Forecast, Models, Ambient
- Live Radar: select "Move map", then arrows pan, OK zooms in, Back zooms out; Menu returns to the layer bar;
  Play/Pause toggles the loop. Ambient mode starts after 10 minutes idle.
- Test on an emulator: Android Studio > Device Manager > Television (1080p) image, install the debug APK.

Code layout
- app/src/main/assets/wp-core.js      shared helpers + every WeatherPower server path (API object)
- app/src/main/assets/wp-radar31.js   Radar 3.1 sheet framework, radar products, color tables, MRMS
- app/src/main/assets/wp-studio.js    Model Studio engine (phone + TV) and point soundings
- app/src/main/assets/wp-travel.js    gas stations, tornado shelters, route weather
- app/src/main/assets/wp-tropical.js  Tropical Storm Center
- app/src/main/assets/wp-tv.js        Android TV shell
- app/src/main/assets/wp-extras.css   styles for all of the above
- MainActivity: TV detection bridge (isTelevision, setKeepScreenOn), JS-aware Back, media/menu keys,
  non-image file picker for palettes, external links open in the browser

Server contract: matches the Radar 3.1 web blocks (radar-3.1-model-studio.html): /api/radar (3-letter site
ids), /api/mrms, /api/models, /api/sounding, /wpcc-api/sounding, /gas/dots.js + /gas/t/<lat>_<lon>.js,
/data/tornado-shelters.json, /api/palette-fetch. After changing any wp-* file, bump its ?v= in index.html
(the service worker caches these files by URL).

CI: .github/workflows/android-debug.yml builds a debug APK on every push and uploads it as an artifact.
